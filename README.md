# Monitoramento de Reservatório

Este projeto simula um sistema de monitoramento de níveis de água para um reservatório.

# Funcionalidades

- Exibição de 5 níveis de alerta com cores distintas.
- Uso de **Colorama** para destacar o status crítico ou de alerta.
- Lógica estruturada em funções para facilitar a manutenção.
- Reset automático de estilos do terminal após a execução.

# Tecnologias e Bibliotecas

- **Python 3**
- **Colorama**: Biblioteca para estilização de cores no terminal (`Fore` e `Style`).
